## 1. 全域介面規則

### 1.1 介面語言

首個版本以繁體中文作為主要介面語言。

一般操作、問候及生活情境可以適量使用自然的香港粵語表達，例如：

- 今晚煮乜？
- 仲未諗到？
- 想快啲煮好
- 想食得健康啲
- 唔想洗太多嘢
- 想轉吓口味
- 開始煮啦

以下內容必須使用清晰、正式的繁體中文：

- 食物過敏；
- 食品安全；
- 私隱及資料使用；
- 帳戶及資料刪除；
- 醫療及營養免責聲明；
- 可能影響使用者健康或安全的系統錯誤。

### 1.2 導航方式

首個版本暫定使用以下底部導航：

- 廚房；
- 煮食紀錄。

底部導航不會加入「我的」。

個人中心統一由廚房首頁右上角的使用者頭像進入。

低保真原型階段需要比較：

- 保留兩項式底部導航；
- 取消底部導航，改由廚房首頁進入煮食紀錄。

最終方案在原型測試後決定。

### 1.3 主要按鈕

每個頁面原則上只設置一個最主要的操作按鈕。

主要按鈕例子：

- 開始使用；
- 下一步；
- 完成設定；
- 開始煮飯；
- 幫我諗吓；
- 儲存；
- 完成呢一步。

次要操作應使用文字按鈕、外框按鈕或返回操作。

### 1.4 返回與離開

除歡迎頁及廚房首頁外，所有頁面均需要提供清晰的返回方式。

進入分步煮食模式後，如果使用者嘗試離開，系統需要提示目前進度會被保留。

### 1.5 安全限制

如果菜式包含使用者已設定的過敏原或明確禁忌食材，系統不得讓使用者直接開始煮食。

系統不得為了增加推薦結果而自動放寬：

- 食物過敏；
- 飲食禁忌；
- 宗教飲食限制；
- 使用者明確表示不會食用的食材。

# 2. 頁面規格

## S01 歡迎頁｜Welcome

### 頁面目的

向首次使用者介紹 Smart Kitchen，並提供開始使用或登入帳戶的入口。

### 進入方式

- 首次開啟應用程式；
- 使用者登出後返回；
- 使用者尚未建立本地資料或登入狀態失效。

### 頁面內容

- Smart Kitchen 標誌；
- 項目名稱；
- 一句簡短產品介紹；
- 廚房主題背景或簡單廚房輪廓；
- 「開始使用」主要按鈕；
- 「已有帳戶？登入」次要入口。

### 主要文案

```text
今晚煮乜？

睇吓屋企有咩材料，
幫你諗好今晚食乜。
```

### 按鈕

```text
開始使用
已有帳戶？登入
```

### 互動

- 點擊「開始使用」→ S02 帳戶頁的註冊狀態；
- 點擊「已有帳戶？登入」→ S02 帳戶頁的登入狀態。

### 原型階段說明

低保真原型需要保留完整登入及註冊畫面。

技術開發初期可以使用模擬登入或本地演示帳戶，不需要立即完成正式電郵驗證。

## S02 帳戶頁｜Authentication

### 頁面目的

讓新使用者建立帳戶，或讓現有使用者登入。

### 頁面狀態

本頁包含兩種主要狀態：

- 註冊；
- 登入。

### A. 註冊狀態

#### 頁面內容

- 電郵地址輸入框；
- 密碼輸入框；
- 確認密碼輸入框；
- 顯示或隱藏密碼按鈕；
- 註冊按鈕；
- 切換至登入的入口。

#### 主要文案

```text
建立帳戶

建立帳戶後，你可以保存食材、
飲食偏好及煮食紀錄。
```

#### 輸入欄位

```text
電郵地址
密碼
確認密碼
```

#### 按鈕

```text
註冊
已有帳戶？登入
```

#### 互動

- 成功註冊 → S03 基本個人資料；
- 點擊「已有帳戶？登入」→ 切換至登入狀態；
- 點擊返回 → S01 歡迎頁。

#### 錯誤文案

```text
請輸入有效的電郵地址。
密碼最少需要 8 個字元。
兩次輸入的密碼並不相同。
此電郵地址已經建立帳戶。
暫時未能建立帳戶，請稍後再試。
```

### B. 登入狀態

#### 主要文案

```text
歡迎返嚟

登入後繼續管理你的雪櫃
同煮食紀錄。
```

#### 輸入欄位

```text
電郵地址
密碼
```

#### 按鈕

```text
登入
忘記密碼？
未有帳戶？立即註冊
```

#### 互動

- 成功登入 → S08 廚房首頁；
- 點擊「未有帳戶？立即註冊」→ 切換至註冊狀態；
- 點擊「忘記密碼？」→ 顯示暫未開放提示或密碼重設頁；
- 點擊返回 → S01 歡迎頁。

#### 錯誤文案

```text
電郵地址或密碼不正確。
暫時未能登入，請檢查網絡後再試。
```

## S03 基本個人資料｜Basic Profile

### 頁面目的

取得使用者的稱呼及頭像，建立基本個人身份。

本頁同時可作為個人中心的資料修改頁。

### 進入方式

- 新使用者完成註冊後；
- 使用者在廚房首頁點擊右上角頭像後，以編輯狀態進入。

### 首次設定文案

```text
等我哋認識你先

想我哋點稱呼你？
```

### 頁面內容

- 設定進度：步驟 1／5；
- 暱稱輸入框；
- 預設頭像選擇；
- 下一步按鈕。

### 輸入欄位

```text
你的暱稱
```

### 按鈕

```text
下一步
```

### 互動

- 選擇預設頭像；
- 輸入暱稱；
- 點擊「下一步」→ S04 過敏及飲食限制；
- 編輯狀態點擊「儲存」→ 返回 S08 廚房首頁。

### 驗證規則

- 暱稱不能為空；
- 暱稱長度暫定為 1–20 個字元；
- 不要求使用者上傳真實照片；
- 第一版只提供預設頭像。

### 錯誤文案

```text
請輸入你希望我哋點稱呼你。
暱稱不能多於 20 個字元。
```

## S04 過敏及飲食限制｜Allergies and Restrictions

### 頁面目的

收集使用者已知的食物過敏及不可違反的飲食限制。

### 進入方式

- S03 基本個人資料；
- 個人中心修改飲食資料。

### 頁面內容

- 設定進度：步驟 2／5；
- 食物過敏原選項；
- 飲食限制選項；
- 其他過敏或限制輸入框；
- 安全提示；
- 上一步及下一步按鈕。

### 主要文案

```text
食物過敏及飲食限制

為協助篩選不適合你的菜式，
請選擇你已知的食物過敏原。
```

### 食物過敏選項

```text
□ 花生
□ 堅果
□ 牛奶
□ 雞蛋
□ 小麥
□ 大豆
□ 魚類
□ 甲殼類海鮮
□ 其他
□ 暫無已知食物過敏
```

### 飲食限制選項

```text
□ 素食
□ 純素
□ 清真飲食
□ 不吃牛肉
□ 不吃豬肉
□ 其他
□ 暫無飲食限制
```

### 安全提示

```text
本功能只根據你提供的資料協助篩選菜式，
不能取代專業醫療意見。

使用食材前，請自行核對產品包裝、成分
及實際食物狀況。
```

### 按鈕

```text
上一步
下一步
```

### 互動

- 點擊「上一步」→ S03 基本個人資料；
- 點擊「下一步」→ S05 飲食目標及口味；
- 選擇「暫無已知食物過敏」後，其他過敏選項自動取消；
- 選擇具體過敏原後，「暫無已知食物過敏」自動取消。

### 驗證規則

使用者必須：

- 選擇至少一項過敏原；
- 或明確選擇「暫無已知食物過敏」。

### 錯誤文案

```text
請選擇已知食物過敏原，
或選擇「暫無已知食物過敏」。
```

```text
你最近想點樣食？
```

```text
□ 清淡
□ 香辣
□ 酸甜
□ 濃味
□ 湯類
□ 香脆
□ 想試新口味
□ 冇特別偏好
```

### 按鈕

```text
上一步
下一步
```

```text
請選擇一個主要飲食目標。
```

## S07 設定確認及新手引導｜Profile Summary and Tutorial

### 頁面目的

讓使用者確認個人飲食檔案，並透過簡短提示介紹廚房首頁。

### 進入方式

- S06 廚藝、工具、時間及預算。

### A. 設定確認狀態

#### 主要文案

```text
設定完成！

Jason，你的煮食偏好已經準備好。
```

#### 資料摘要示例

```text
主要目標：食得健康啲
廚藝程度：新手
一般時間：30 分鐘內
每餐預算：HK$30–50
食物過敏：花生
常用工具：平底鑊、電飯煲
```

#### 按鈕

```text
修改設定
入去睇吓
```

#### 互動

- 點擊「修改設定」→ 返回相應設定頁；
- 點擊「入去睇吓」→ S08 廚房首頁，並啟動新手引導。

### B. 新手引導狀態

新手引導以覆蓋在廚房首頁上的提示層呈現，不使用多個獨立教學頁面。

#### 第一步

突出雪櫃：

```text
管理你屋企現有嘅食材，
仲可以睇吓有咩就快到期。
```

按鈕：

```text
下一個
```

#### 第二步

突出煮食爐：

```text
準備好就撳「開始煮飯」，
我哋會幫你搜尋或者推薦菜式。
```

按鈕：

```text
下一個
```

#### 第三步

突出右上角頭像：

```text
想修改飲食偏好、過敏資料
或者其他設定，可以撳呢度。
```

按鈕：

```text
知道啦
```

#### 互動

- 點擊「知道啦」→ 關閉引導，停留在 S08 廚房首頁；
- 首個版本只會在首次進入時自動顯示；
- 個人中心可以提供「再次查看新手引導」。

## S08 廚房首頁｜Kitchen Home

### 頁面目的

作為應用程式的主要入口，讓使用者查看食材提醒、管理雪櫃、開始煮飯及進入個人設定。

### 進入方式

- 完成 S07 首次設定；
- 登入成功；
- 點擊底部「廚房」；
- 完成煮食及回饋後返回；
- 從其他頁面返回首頁。

### 頁面內容

- 右上角使用者頭像；
- 根據時間變化的窗戶；
- 留言板；
- 可互動的雪櫃；
- 可互動的煮食爐；
- 「開始煮飯」主要按鈕；
- 暫定底部導航；
- 臨期食材提示。

### 主要文案

早上：

```text
早晨，Jason
今日想食啲乜？
```

下午：

```text
下晝好，Jason
今餐想食啲乜？
```

晚上：

```text
晚上好，Jason
今晚想食啲乜？
```

深夜：

```text
夜喇，Jason
想整啲簡單嘢食？
```

### 雪櫃資訊

正常狀態：

```text
雪櫃有 8 種食材
```

臨期狀態：

```text
2 種食材就快到期
```

### 煮食爐文案

```text
開始煮飯
```

### 暫定底部導航

```text
廚房
煮食紀錄
```

底部不設置「我的」。

### 互動

- 點擊使用者頭像 → S03，以個人中心／編輯狀態顯示；
- 點擊雪櫃 → S09 雪櫃管理；
- 點擊煮食爐 → S11 開始煮飯；
- 點擊「開始煮飯」→ S11 開始煮飯；
- 點擊臨期提醒 → S09，並自動切換至「就快到期」分類；
- 點擊「煮食紀錄」→ 顯示煮食紀錄列表。

### 時間顯示規則

首個版本根據裝置本地時間顯示：

- 05:00–11:59：早上；
- 12:00–17:59：下午；
- 18:00–23:59：晚上；
- 00:00–04:59：深夜。

首個版本不需要接入真實天氣 API。

### 空狀態

如果雪櫃沒有食材：

```text
雪櫃仲未有食材

加啲屋企現有嘅材料，
我哋先可以幫你推薦合適菜式。
```

按鈕：

```text
加入食材
```

### 資料錯誤狀態

```text
暫時讀取唔到雪櫃資料。
```

按鈕：

```text
再試一次
```

- 再次查看菜式的入口。

### 空狀態

```text
仲未有煮食紀錄

完成第一道菜後，
你可以喺度睇返自己的煮食歷程。
```

按鈕：

```text
開始煮飯
```

## 3.3 臨期食材提醒

一般情況不使用阻擋式彈窗。

如食材預計在一天內到期，可以顯示：

```text
蘑菇預計明日到期

要唔要優先推薦使用蘑菇嘅菜式？
```

按鈕：

```text
優先使用
稍後提醒
已經處理
```

底部說明：

```text
到期日只供參考。進食前請檢查食材的
氣味、外觀、包裝及實際保存狀況。
```

# 4. 全域狀態規格

## 4.1 載入狀態

推薦載入：

```text
等我哋幫你諗吓……
```

資料載入：

```text
正在讀取資料……
```

儲存資料：

```text
正在儲存……
```

載入狀態應提供視覺提示，並避免使用者重複提交。

## 4.2 網絡錯誤

```text
暫時連接唔到服務

請檢查網絡後再試，
或者先使用已儲存的資料。
```

按鈕：

```text
再試一次
使用已儲存資料
```

## 4.3 一般錯誤

```text
發生咗少少問題

請稍後再試。
```

按鈕：

```text
再試一次
返回廚房
```

涉及安全、過敏或資料遺失的錯誤，不應使用過於輕鬆或含糊的口語。

## 4.4 無推薦結果

```text
暫時搵唔到完全符合條件嘅菜式

你可以增加可用時間、調整預算，
或者加入更多食材。

食物過敏及飲食禁忌不會被自動放寬。
```

## 4.5 成功提示

```text
已經儲存。
已經加入雪櫃。
食材資料已更新。
煮食紀錄已儲存。
個人設定已更新。
```
