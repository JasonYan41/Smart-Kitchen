# Smart Kitchen 使用者流程｜User Flow

> 本文件只記錄主要使用者流程、判斷分支及頁面跳轉。
>
> 頁面內容、按鈕文案、表單驗證及畫面狀態請參考 `screen-specifications.md`。

---

## 1. 首次使用流程

```text
開啟應用程式
→ S01 歡迎頁
→ 選擇「開始使用」或「登入」
```

### 新使用者

```text
開始使用
→ S02 註冊
→ 註冊成功
→ S03 設定暱稱及頭像
→ S04 設定食物過敏及飲食限制
→ S05 選擇主要飲食目標及口味偏好
→ S06 設定廚藝程度、煮食工具、時間及預算
→ S07 確認個人飲食檔案
→ 完成新手引導
→ S08 廚房首頁
```

如果注册失败：

```text
註冊失敗
→ 顯示錯誤
→ 返回 S02 修改資料
→ 再次提交
```

### 現有使用者

```text
登入
→ 讀取個人資料
```

如果已经完成个人饮食档案：

```text
個人飲食檔案已完成
→ S08 廚房首頁
```

如果尚未完成个人饮食档案：

```text
個人飲食檔案尚未完成
→ 返回未完成的設定步驟
→ 完成其餘設定
→ S07 確認個人飲食檔案
→ S08 廚房首頁
```

如果登录失败：

```text
登入失敗
→ 顯示錯誤
→ 留在 S02 登入頁
```

---

## 2. 新手引導流程

```text
完成個人飲食檔案
→ 進入 S08 廚房首頁
→ 顯示雪櫃提示
→ 顯示煮食爐提示
→ 顯示右上角使用者頭像提示
→ 完成引導
→ 留在 S08 廚房首頁
```

使用者之后可以从个人中心再次查看新手引导。

---

## 3. 雪櫃管理流程

```text
S08 廚房首頁
→ 點擊雪櫃
→ S09 雪櫃管理
→ 查看現有食材
```

使用者可以：

- 加入食材；
- 修改食材；
- 將食材標記為已用完；
- 刪除食材；
- 查看臨期食材；
- 根據指定食材尋找菜式。

### 加入食材

```text
S09 雪櫃管理
→ 點擊「加入食材」
→ S10 加入食材
→ 填寫食材資料
→ 儲存
→ 返回 S09 雪櫃管理
```

如果资料不完整或不正确：

```text
儲存失敗
→ 顯示錯誤
→ 留在 S10
→ 修改資料
→ 再次儲存
```

### 修改食材

```text
S09 雪櫃管理
→ 選擇食材
→ S10 編輯食材
→ 修改資料
→ 儲存
→ 返回 S09 雪櫃管理
```

### 標記為已用完

```text
S09 雪櫃管理
→ 選擇食材
→ 標記為已用完
→ 確認
→ 更新雪櫃
→ 返回 S09 雪櫃管理
```

### 刪除食材

```text
S09 雪櫃管理
→ 選擇食材
→ 刪除食材
→ 顯示確認
```

如果确认删除：

```text
確認刪除
→ 更新雪櫃
→ 返回 S09 雪櫃管理
```

如果取消：

```text
取消
→ 關閉確認
→ 留在 S09 雪櫃管理
```

### 雪櫃空狀態

```text
S09 雪櫃管理
→ 沒有食材
→ 顯示空狀態
→ 點擊「加入第一種食材」
→ S10 加入食材
```

## 4. 臨期食材提醒流程

```text
進入 S08 廚房首頁
→ 系統檢查食材到期日
```

如果没有临期食材：

```text
沒有臨期食材
→ 顯示一般雪櫃狀態
→ 留在 S08 廚房首頁
```

如果发现临期食材：

```text
發現臨期食材
→ 顯示提醒
```

使用者可以选择：

- 優先使用；
- 稍後提醒；
- 已經處理。

### 優先使用

```text
選擇「優先使用」
→ S12 推薦條件
→ 自動加入臨期食材
→ 自動選取臨期食材條件
→ 使用者確認其他條件
→ 產生推薦
```

### 稍後提醒

```text
選擇「稍後提醒」
→ 關閉提醒
→ 保留臨期狀態
→ 留在 S08 廚房首頁
```

### 已經處理

```text
選擇「已經處理」
→ 選擇處理方式
```

处理方式：

```text
已經用完
→ 更新雪櫃
→ 留在 S08 廚房首頁
```

```text
已經丟棄
→ 更新雪櫃
→ 留在 S08 廚房首頁
```

```text
修改到期日
→ S10 編輯食材
→ 儲存
→ 返回雪櫃或廚房首頁
```

## 5. 開始煮飯流程

```text
S08 廚房首頁
→ 點擊煮食爐或「開始煮飯」
→ S11 開始煮飯
→ 系統詢問「今晚有冇諗到食乜？」
```

使用者可以选择：

- 已經諗好；
- 仲未諗到；
- 優先使用臨期食材。

### 已經諗好

```text
選擇「已經諗好」
→ 進入菜式搜尋
→ 輸入菜式名稱
→ 顯示搜尋結果
```

### 仲未諗到

```text
選擇「仲未諗到」
→ S12 推薦條件
```

### 優先使用臨期食材

```text
選擇「優先使用臨期食材」
→ 讀取臨期食材
```

如果有临期食材：

```text
加入臨期食材條件
→ S12 推薦條件
```

如果没有临期食材：

```text
沒有臨期食材
→ 顯示提示
→ 進入一般推薦
→ S12 推薦條件
```

---

## 6. 已經諗好流程

```text
選擇「已經諗好」
→ 輸入菜式名稱
→ 搜尋菜式
```

如果找到结果：

```text
顯示搜尋結果
→ 選擇菜式
→ 系統檢查食材、工具、過敏及飲食限制
```

如果没有找到结果：

```text
沒有搜尋結果
→ 修改搜尋內容
```

或：

```text
選擇「幫我推薦」
→ S12 推薦條件
```

### 符合限制

```text
菜式符合過敏及飲食限制
→ S14 菜式詳情
→ 開始煮飯
→ 分步煮食
```

### 包含過敏原

```text
發現已設定的食物過敏原
→ 顯示阻擋提示
→ 不允許開始煮食
```

使用者可以：

```text
返回搜尋結果
```

或：

```text
進入個人中心
→ 查看過敏及飲食限制
```

### 不符合其他飲食限制

```text
菜式不符合飲食限制
→ 顯示不符合的原因
→ 返回搜尋結果
```

---

## 7. 仲未諗到流程

```text
S11 開始煮飯
→ 選擇「仲未諗到」
→ S12 推薦條件
→ 選擇最重視的條件
→ 設定可用時間
→ 設定預算
→ 設定用餐人數
→ 提交推薦條件
```

系统处理：

```text
檢查過敏及飲食限制
→ 排除不符合硬性限制的菜式
→ 根據食材、時間、預算及偏好排序
```

### 成功找到推薦

```text
找到合適菜式
→ S13 推薦結果
→ 顯示三個主要推薦
→ 查看推薦理由
→ 選擇菜式
→ S14 菜式詳情
```

### 沒有符合條件的推薦

```text
未能找到合適菜式
→ 顯示無推薦結果
→ 返回 S12 推薦條件
→ 修改條件
→ 再次提交
```

食物过敏及饮食限制不会被系统自动放宽。

### 推薦服務失敗

```text
推薦服務失敗
→ 保留目前推薦條件
```

使用者可以：

```text
再次嘗試
```

或：

```text
查看已儲存的菜式
```

---

## 8. 推薦結果流程

```text
S13 推薦結果
→ 查看推薦菜式
→ 查看推薦理由
```

使用者可以：

### 查看完整菜式

```text
選擇菜式
→ S14 菜式詳情
```

### 修改條件

```text
選擇「修改條件」
→ 返回 S12 推薦條件
→ 保留原有選項
→ 修改條件
→ 再次產生推薦
```

### 再揀過

```text
選擇「再揀過」
→ 保留原有條件
→ 顯示其他候選菜式
```

---

## 9. 菜式詳情及分步煮食流程

```text
S14 菜式詳情
→ 查看食材、工具、時間、費用及推薦理由
→ 系統再次檢查過敏及飲食限制
```

如果符合限制：

```text
點擊「開始煮飯」
→ 進入分步煮食
```

如果发现过敏或饮食限制冲突：

```text
顯示阻擋提示
→ 不允許開始煮食
→ 返回 S13 推薦結果
```

### 分步煮食

```text
查看目前步驟
→ 完成操作
→ 進入下一步
→ 重複直至最後一步
→ 完成煮食
→ S15 完成及回饋
```

### 中途離開

```text
使用者嘗試離開
→ 顯示確認
```

如果继续煮食：

```text
留在目前步驟
```

如果暂时离开：

```text
保存目前進度
→ 返回 S08 廚房首頁
```

再次进入时：

```text
發現未完成的煮食流程
→ 選擇繼續煮飯
→ 返回上次未完成的步驟
```

---

## 10. 完成及回饋流程

```text
S15 完成及回饋
→ 使用者選擇是否填寫回饋
```

### 提交回饋

```text
填寫回饋
→ 儲存煮食紀錄
```

如果储存成功：

```text
儲存成功
→ 返回 S08 廚房首頁
```

或：

```text
儲存成功
→ 查看煮食紀錄
```

如果储存失败：

```text
儲存失敗
→ 保留已輸入資料
→ 再次嘗試
```

或：

```text
稍後處理
→ 暫存在本地
→ 返回 S08 廚房首頁
```

### 跳過回饋

```text
選擇跳過
→ 保存基本完成紀錄
→ 返回 S08 廚房首頁
```

## 11. 煮食紀錄流程

如果保留底部导航：

```text
S08 廚房首頁
→ 點擊「煮食紀錄」
→ 查看過往煮食紀錄
```

如果低保真测试后取消底部导航：

```text
S08 廚房首頁
→ 點擊煮食紀錄入口
→ 查看過往煮食紀錄
```

### 查看過往紀錄

```text
選擇一項紀錄
→ 查看過往煮食結果
→ 查看菜式詳情
```

### 再次煮食

```text
選擇「再次煮食」
→ 系統重新檢查目前食材及飲食限制
→ S14 菜式詳情
→ 開始煮飯
```

### 沒有煮食紀錄

```text
沒有煮食紀錄
→ 顯示空狀態
→ 點擊「開始煮飯」
→ S11 開始煮飯
```

## 12. 個人中心流程

```text
S08 廚房首頁
→ 點擊右上角使用者頭像
→ 進入個人中心
```

个人中心只通过右上角头像进入，不设置底部“我的”。

使用者可以：

- 修改昵称及头像；
- 修改食物过敏及饮食限制；
- 修改饮食目标及口味；
- 修改厨艺程度及煮食工具；
- 修改一般时间及预算；
- 修改临期食材通知；
- 再次查看新手引导；
- 登出。

### 修改設定

```text
個人中心
→ 選擇設定項目
→ 進入相應設定頁
→ 修改資料
→ 儲存
→ 返回個人中心
```

### 再次查看新手引導

```text
個人中心
→ 選擇「再次查看新手引導」
→ S07 新手引導
→ 完成引導
→ S08 廚房首頁
```

### 登出

```text
個人中心
→ 選擇「登出」
→ 顯示確認
```

如果确认：

```text
登出
→ S01 歡迎頁
```

如果取消：

```text
關閉確認
→ 留在個人中心
```
